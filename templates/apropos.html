À propos

Bienvenue sur notre application web dédiée à l'analyse et à la visualisation des données de santé publique issues de data.ameli.fr. Notre objectif est de rendre ces données accessibles et compréhensibles pour tous.

Fonctionnalités principales

Python Flask Pandas Matplotlib HTML/CSS JavaScript

Comment utiliser l'application

  1. L'application se connecte à une base de données SQLite3 locale. Veillez à ce que cette base soit correctement configurée et contienne toutes les données nécessaires pour son bon fonctionnement.
  2. La visualisation du contenu des tables s'effectue à l'aide de requêtes SQLite exécutées via Pandas, permettant de récupérer et d'afficher les données des tables.
  3. Sélectionner des données : Utiliser la technique des jointures SQL.
  4. Visualisation des données : Visualisez et analysez les données de différentes tables en utilisant des formulaires ou encore une carte interactive.
  5. Représentations graphiques : Consultez un histogramme des données ou un diagramme circulaire via Matplotlib pour une représentation visuelle des données.
